■ 需要什么

· Windows 10 / 11（64 位）
· 内存 8 GB 起（16 GB 更稳）
· 硬盘约 1.5 GB（解压后约 600 MB，加上她的记忆数据）
· 一条能上网的网线/WiFi —— 聊天要联网（发出去的只有你这句话和必要上下文），记忆和记录都在本机

■ 怎么开始（第一次大约 5 分钟）

1) 用安装包：双击 Yueyue-Setup-0.3.0-beta.10.exe，按提示选安装位置。默认装到当前用户目录，不需要管理员权限；不要装进会同步的网盘。
   用便携包：把整个文件夹解压到你找得到的地方（例如 D:\玥玥\），不要放 C:\Program Files，也不要放会同步的网盘。

2) 安装版从开始菜单/桌面打开「玥玥」；便携版双击文件夹里的 玥玥.exe。
   如果 Windows 弹出「已保护你的电脑」——点「更多信息」→「仍要运行」。
   （这个版本没做数字签名，所以会有这个提示，不是病毒。）

3) 第一次打开会走五步，跟着点就行：
   ① 选年龄（要年满 18 岁）
   ② 她说一遍她是谁 —— 点「进入安全屋」
   ③ 勾选「我已阅读并同意」才能继续（不同意就是退出，这是硬性的）
   ④ 勾几个标签，决定她的性格底色（最多 12 个，选完点「完成设定」）
   ⑤ 点「唤醒玥玥」，进入主界面

4) 填一把钥匙（不填她不会说话，只能看界面）
   右上角「设置」→「模型与密钥」→ 把 DeepSeek 的 API Key 粘进去 → 保存。
   钥匙怎么来：这一轮 15 个名额都请你自己注册一把 DeepSeek API Key（自备 Key，不共享）。
   自己注册：platform.deepseek.com → 创建 API Key。
   注意：这把钥匙只在你自己的电脑上用，不要发给别人，也不要在群里贴。

5) 回到主界面，在下面输入框里跟她说话。

■ 这个体验包的实情

1) 没有语音包，所以她只打字，不出声。
   语音需要几个 GB 的本地模型，这一版没带。要听声音的版本另外装。
2) 聊天质量取决于你填的那把钥匙和选哪个模型。
   设置里默认是 DeepSeek V4.1-Flash，够用；想更好可以切 V4-Pro（更贵）。
3) 记忆导出现在是「完整备份」：派生记忆、聊天原文、图片和隐藏画像四张表都在一个 JSON 里，
   不含设置和 API Key。导入时可预览、合并或覆盖；覆盖前会自动再导出当前数据；
   「撤销上次导入」只在本次打开期间有效，重启后就不能再撤销。
   人格包（.soul）只含设定，不是记忆。
4) 回复过程中可以点输入框旁边的「停止」；已经生成的部分会留在屏幕上。

■ 你的数据在哪（这次写清楚）

· 程序文件夹：你解压/安装的位置。删掉它，不会删掉你的聊天和记忆。
· 数据文件夹：C:\Users\<你的用户名>\AppData\Roaming\yueyueapp
  设置 →「关于」里能看到你这台机器上的确切路径；点「📂 打开数据文件夹」可以直接打开。
· 备份：先退出玥玥，再把整个 yueyueapp 文件夹拷走。
· 清空：设置 →「恢复出厂设置」。它会清掉聊天原文、记忆、成就和钥匙，并先提醒你导出；
  建议先在记忆面板点「导出完整备份」。
  不要只删 yueyueapp 文件夹——那只删一部分，程序下次启动还可能重建它。
· 卸载：安装版用 Windows「设置 → 应用 → 玥玥 → 卸载」，或开始菜单里的「卸载 玥玥」；便携版直接删掉程序文件夹。卸载程序不会删掉 yueyueapp 里的记忆。
  要彻底删除：先导出你还需要的内容（或确认不再需要），打开玥玥「恢复出厂设置」清空数据，退出程序后再手动删掉 yueyueapp 文件夹。

■ 卡住了怎么办

· 双击没反应 / 白屏：先把整个文件夹移到 D 盘根目录再试一次（路径里有奇怪字符、或者放在了同步盘里，都可能出问题）。
· 提示缺少 dll 或打不开：截图发给我（连同 Windows 版本）。
· 说「钥匙无效」：检查 key 有没有复制全、余额是否够。
· 回复一直不出来：等 30 秒左右，仍没动静就点「停止」，再发一次；把当时屏幕截图给我。
· 其他任何不对劲：截图 + 一句话描述你在做什么，发给我。
